ÇAY ÜRETİCİSİ YÖNETİM SİSTEMİ V2

Windows:
1. Python 3 kurulu olmalı.
2. Bu klasörde BUILD_EXE.bat dosyasına çift tıklayın.
3. İşlem bitince dist klasöründeki CayUreticisiV2.exe dosyasını çalıştırın.

V2 özellikleri:
Dashboard, günlük hasat/satış, tahsilat, alacak, gider, kasa, bahçeler,
KG/dönüm, tüm kayıtlar, veritabanı yedekleme ve CSV içe aktarma.

CSV içe aktarma başlıkları:
tarih,surum,bahce,kg,firma,fiyat,tahsilat,aciklama
